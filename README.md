# 🧠 Market Basket Analysis & Visualization System

This project implements a complete **Machine Learning pipeline** to analyze transactional datasets and extract meaningful patterns using the **Apriori Algorithm**.

## 🚀 Features

* Automatic CSV dataset parsing (supports multiple formats)
* Frequent itemset generation using Apriori
* Association rule mining based on:

  * Support
  * Confidence
  * Lift
* Dynamic visualization engine

## 📊 Visualizations Included

* Top frequent items (Bar chart)
* Support vs Confidence (Scatter plot)
* Confidence heatmap (Rule relationships)
* Lift-based ranking (Bar chart)

## ⚙️ Tech Stack

* Python (Flask backend)
* Pandas, NumPy
* MLxtend
* Matplotlib, Seaborn

## 💡 Use Cases

* Retail purchase analysis
* Recommendation systems
* Customer behavior insights

## 📁 API Example

Upload dataset → Process → Generate insights → Visualize patterns

## 📌 Output

* Summary statistics
* Frequent itemsets
* Association rules
* Downloadable CSV results
